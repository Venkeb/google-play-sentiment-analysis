Google Play App Reviews – Sentiment Analysis (Power BI)
Project Overview:
Analyzed Google Play Store user reviews to understand customer sentiment and app performance.
Built an interactive Power BI dashboard for sentiment and rating analysis.

Objective:
Understand customer sentiment (Positive, Neutral, Negative).
Identify apps and categories with high negative feedback.
Track review and rating trends over time.
Dataset
App-level dataset (App name, category, ratings).
Review-level dataset (User reviews, sentiment, review date).

Tools Used
Power BI
Power Query
DAX
Excel / CSV

Data Cleaning & Transformation:
Removed duplicate and null values
Standardized sentiment categories
Cleaned review text
Built relationships between datasets

Key Insights
Identified apps with high negative feedback
Found categories needing improvement
Highlighted trends in user sentiment

Conclusion
This project demonstrates skills in data cleaning, data modeling, DAX, and dashboard creation using Power BI.
